# Изменения

## Документация GitHub — 2026-10-14

- README дополнен кратким описанием возможностей, технологий и скриншотом интерфейса.
- Скриншот хранится в `docs/screenshots/interface.png` и подключён относительной ссылкой.
- Каталог документации включён в сборку full и update, чтобы изображение README оставалось доступным в архиве.

## v1.1.0 — 2026-10-08

- Название Sign No Scan для сайта `sign-no-scan`, новый заголовок «Ваша подпись на документе».
- Выбор сохранения: исходный формат, PNG, JPG, PDF, Word (.docx).
- PNG/JPG всех страниц, одна картинка напрямую или ZIP нескольких страниц; JPG с белым фоном и качеством 95%.
- Word → PDF/картинки повторяет браузерный предпросмотр с наложенными подписями.
- PDF → Word создаёт страницы-картинки с сохранением размеров; интерфейс объясняет отсутствие редактируемого текста.
- Пакетная конвертация смешанных документов, восстановление выбранного Word и страницы после экспорта.
- Ограничение площади картинок и памяти, локальный html-to-image, без передачи документов на сервер.
- Проверки конвертации включают цвета подписи, поворот, CropBox, размеры и пакет разных DOCX.

## v1.0.0 — 2026-10-08

- Самостоятельная PHP-утилита с тёмным адаптивным интерфейсом, без БД и обязательной сборки.
- Просмотр PDF и Word (.docx), несколько документов и страниц.
- Загрузка фотографии подписи, ручное выделение, удаление фона, поворот фотографии и рисование мышью/пальцем.
- Перемещение, размер в миллиметрах, поворот, копирование, удаление, отмена и повтор действий.
- Экспорт PDF с сохранением исходных страниц; DOCX с добавленными плавающими изображениями; ZIP нескольких подписанных документов.
- Документы только в памяти браузера. Подписи в localStorage только по явному включению.
- Локальные библиотеки, изолированный просмотр DOCX, ограничения размеров файлов и распакованных архивов.
- Запуск и остановка локального сервера в Windows, инструкции для PHP-хостинга.
